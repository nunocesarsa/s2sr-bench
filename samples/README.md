# Sample scenes

Downloaded sample areas live here, one folder each (`s2_l2a.tif`, `highres.tif`, `info.json`).
They are not stored in Git. Create them with:

- Windows: `download_sample.bat` (or `download_sample.bat all`)
- Linux/WSL: `python -m s2sr.cli sample --preset all`

See [docs/Sample-scenes.md](../docs/Sample-scenes.md).
